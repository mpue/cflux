## Wie Screenshots erstellen?

1. System starten: `docker-compose up -d`
2. Als Admin einloggen (admin@timetracking.local / admin123)
3. Zum jeweiligen Modul navigieren
4. Browser-Fenster auf 1920x1080 setzen
5. Screenshot machen (am besten mit vollem Datenbestand für realistische Ansicht)
6. Bild auf ca. 1200x800px skalieren und optimieren
7. Als PNG im `web/` Verzeichnis speichern
